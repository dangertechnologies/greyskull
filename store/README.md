# Store listing, Greyskull LP 1.1.0

Everything the App Store and Google Play listings need. Text is in `copy.md`; images are generated by
`python3 store/make-screenshots.py` from the raw captures in `screenshots/raw/dark`.

## Contents

| Path | Use |
|---|---|
| `copy.md` | All listing text with character counts |
| `store.config.json` | iOS metadata for EAS Metadata (`eas.json` `metadataPath` points here) |
| `android/en-US/` | Play text in fastlane layout (title, short and full description, changelog `2.txt` = versionCode 2) |
| `screenshots/ios-6.9/` | 6 App Store screenshots, 1320x2868 (6.9" display) |
| `screenshots/android-phone/` | 6 Play phone screenshots, 1080x1920 |
| `graphics/play-icon-512.png`, `graphics/play-feature-1024x500.png` | Play icon and feature graphic |
| `site/` | `index`, `support`, `privacy` HTML for GitHub Pages |

## Before you upload

- **App Review contact**: not in `store.config.json` (the repo is public). Fill name, email and phone in App Store Connect, App Review Information.
- **Pages**: privacy and support URLs in the config assume `https://dangertechnologies.github.io/greyskull/`.
  Publish `store/site/*.html` to the root of a `gh-pages` branch and enable Pages, or both stores reject the URLs.
- **Icon alpha**: `assets/icon.png` has an alpha channel (fully opaque). The App Store rejects icons with
  alpha. Expo strips it when building the iOS icon, but if App Store Connect complains, flatten with
  Pillow (`Image.open(...).convert("RGB").save(...)`).
- **Trademarks**: the description does not name StrongLifts or Starting Strength. The app screens do.
- **Widget** has no screenshot (needs a development build, not Expo Go).

## iOS (App Store Connect)

1. `pnpm dlx eas-cli metadata:lint`, then `pnpm dlx eas-cli metadata:push`.
2. Upload `screenshots/ios-6.9/*.png` to the 6.9" iPhone slot (the other iPhone sizes scale from it).
   EAS Metadata does not upload screenshots.
3. App Privacy: **Data Not Collected**. Export compliance is already set (`ITSAppUsesNonExemptEncryption: false`).
4. Age rating: all answers none, result 4+. Category Health & Fitness, secondary Sports.

## Android (Play Console)

1. Store listing: paste `android/en-US/*.txt`. Upload `graphics/play-icon-512.png`, the feature graphic and
   `screenshots/android-phone/*.png`.
2. Data safety: no data collected, none shared. No account, so no deletion URL needed.
3. Content rating (IARC): utility/fitness, every question "No".
4. Ads: none. App access: no restrictions. Target audience: your call (18+ is simplest).
5. Package: `com.greyskull` needs the original upload keystore. Without it, change `android.package` in
   `app.json` to `com.dangertechnologies.gslp` and publish a new listing (see README Release step 3).
   The listing assets work for either package.

## Retaking screenshots

Expo Go on the iPhone 17 Pro Max simulator, dark mode, `xcrun simctl status_bar booted override --time 9:41
--batteryState charged --batteryLevel 100 --cellularBars 4 --wifiBars 3`. Finish setup, run Settings,
Developer, "Seed 3 months of workouts", then capture each route with `xcrun simctl io booted screenshot`
(routes in `docs/UI-REVIEW-2026-10.md`). Run the script afterwards.
